# Experiment Design

Notes on how to design each experiment before running it. One note per experiment.

An experiment design note should record:

- **Question**: what this experiment is meant to answer.
- **Setup**: the allocation problem, mechanism(s), and population or personas involved.
- **Explanation mechanism(s)**: which forms of explanation are compared, from search
  over static documentation to LLM-powered counterfactual generation.
- **Evaluation**: how results are judged, e.g. self-consistency, counterfactual
  robustness, conciseness, sufficiency and necessity, and relevance to the user. Add
  human-centric measures (trust, cognitive load, understanding) if the experiment runs
  with people.
- **Expected outcome**: what would count as success or a surprise.
