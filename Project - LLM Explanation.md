# Project Description
For a diverse set of applications, we rely increasingly much on algorithmic systems for making decisions. Examples include energy markets, traffic, and content recommendations on online platforms. In all these, multiple stakeholders are impacted by the decision the system makes. As such, the goal of the system can rarely be expressed as a single-metric optimization problem. Systems can be efficient yet lack fairness. Even when focusing on fairness alone, there are multiple definitions, and different stakeholders might be interested in different notions. As a result, such technical systems are complex, making it difficult to also be transparent and explainable.

For this pathfinder, we set out to investigate whether LLMs can help better explain algorithmic decisions to users with different backgrounds and priorities. Can they create counterfactual explanations, prioritize the metrics users are most interested in, and provide accessible yet correct explanations?

We start working on one case study. One example could be priority allocations in traffic, but the precise application will be based on the interests and expertise of the team members. For this case study, we import or implement a simulator together with a state-of-the-art decision system. Within this setting, we develop several types of explanations ranging from searches on static documentation to LLM-powered counterfactual generation. To do so, we can use learnings and frameworks from algorithmic recourse. We then evaluate these explanatory mechanisms across several dimensions (e.g., self-consistency, counterfactual robustness, conciseness, sufficiency and necessity for motivating decisions, relevance for the specific user). If time permits, we can also evaluate impact at a human-centric level via experiments (e.g., to test the relative trust, cognitive load, and overall system understanding). An LLM system to provide personalized ex-post explanations in algorithmic decision-making. Even more, we can integrate this LLM system into co-design architectures.
